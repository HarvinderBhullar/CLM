# Research records: CLM vision extension (FracAtlas)

Records kept for a write-up. Every number in a paper should trace to a file here or in `results/`, and
every file to a commit on branch `fracatlas-vision`.

| file | what it holds |
|---|---|
| [log.md](log.md) | chronological log: design decisions, data cleaning, problems and fixes, results per experiment |
| [environment.md](environment.md) | hardware, library versions, model revisions, checksums |
| [protocol_alignment.md](protocol_alignment.md) | pre-registered protocol for the alignment-preserving experiment |
| [claims.md](claims.md) | each claim for the paper, with its number, source file and commit |

Result files (generated by the evaluation scripts, test evaluated once each):

| experiment | report | script |
|---|---|---|
| binary fracture task, calibration | `results/fracatlas.md` (+ `fracatlas_verdict.md`) | `evaluation/vision_eval.py` |
| multi-question, MedSigLIP | `results/fracatlas_multiq_medsiglip.md` | `evaluation/vision_eval_multiq.py` |
| multi-question, Qwen3-VL-4B | `results/fracatlas_multiq_qwen3-vl-4b.md` | `evaluation/vision_eval_multiq.py` |
| alignment-preserving | `results/fracatlas_align_medsiglip.md` | `evaluation/vision_eval_align.py` |
